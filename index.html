FAQ — Google searchable

Is this the same as the GitHub NGL Spammer?

Yes, same Python logic, just with a web UI. Original CLI required pip install requests + terminal. This version runs the same requests from Vercel's Python runtime.

Does it need proxies?

Web version doesn't — Vercel's IP rotates per region. Proxies option is disabled for simplicity. For heavy use, increase delay to avoid NGL's rate limit.

Why Vercel + Python?

You asked for Python that works via Google — Vercel supports Python serverless functions (api/*.py), so we keep Python logic and deploy it to a public HTTPS domain Google can index.

Can I use it on mobile?

Yes — it's responsive, works on iPhone/Android Chrome/Safari. Add to home screen for app-like use. No download.
